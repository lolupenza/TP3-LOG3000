TP3 - LOG3000
Numéro d'équipe : 19
Objectif : Le projet consiste en une calculatrice. L'équipe 19 a la charge de corriger et documenter un projet pré-existant.
Prérequis d'installation : compte Github, Git installé localement, Python 3.8 ou plus récent, et pip installés.
Instructions d'installation : 
1. Sur la page principale du dépôt, aller dans "code" -> clone
2. Copier l'URL HTTPS donné
3. Choisir un emplacement sur votre ordinateur et utiliser la commande "git clone" suivi de l'URL
4. Installer la dépendance : pip install flask
5. Lancer l'application : python app.py.
